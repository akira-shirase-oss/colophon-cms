Connect Colophon to your AI app

This address is Colophon's MCP server. AI apps (Claude, Claude Code, Cursor and others) use it to read and write your content, publish, manage media and members, on your behalf.

Server URL

https://colophonapp.404human.dev/mcp

1. Make a project API token

  1. Open Colophon Studio and go into your project.
  2. Open Settings → API tokens, choose New token (full access, or read-only), and copy it. It starts with colophon_api_.

2. Add it to your app

Claude Code

claude mcp add --transport http colophon https://colophonapp.404human.dev/mcp \
  --header "Authorization: Bearer colophon_api_…"

Cursor, VS Code and other apps (an MCP server entry in their settings)

{
  "mcpServers": {
    "colophon": {
      "url": "https://colophonapp.404human.dev/mcp",
      "headers": { "Authorization": "Bearer colophon_api_…" }
    }
  }
}

Claude.ai and Claude Desktop

Connecting by signing in to Colophon (no token to copy) is coming next. Until then, use Claude Code or an app that accepts the header above.

What it can do, and what stays with you

Every project action the Studio has is available, except deleting a project. Anything that publishes, removes, revokes, or changes who can do what asks you first: the app shows you what it would do, and only goes ahead after you say yes. The token can never do more than its own permissions allow, and you can revoke it in Settings → API tokens at any time.
