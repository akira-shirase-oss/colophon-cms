Connect Colophon to your AI app

This address is Colophon's MCP server. Connect Claude, ChatGPT, Cursor or another AI app, and it can write, publish and manage your projects for you — after you sign in and approve.

Server URL

https://colophonapp.404human.dev/mcp

Connect in three steps

  1. Copy the server URL above.
  2. Add it to your AI app as a custom connector or MCP server (below).
  3. Your app opens Colophon: sign in, choose the project, and approve. That's it — no token to copy.

Claude.ai and Claude Desktop

  1. Open Customize → Connectors, then + Add → Add custom connector.
  2. Name it Colophon and paste https://colophonapp.404human.dev/mcp. Choose Add.
  3. Choose Connect, sign in to Colophon, pick your project and approve.

Claude Code

claude mcp add --transport http colophon https://colophonapp.404human.dev/mcp

Then run /mcp in Claude Code and choose Authenticate: your browser opens Colophon's sign-in.

ChatGPT, Cursor, VS Code and other apps

Add a remote MCP server with the URL above; the app sends you to Colophon to sign in and approve.

{ "mcpServers": { "colophon": { "url": "https://colophonapp.404human.dev/mcp" } } }

Scripts and CI

Something without a browser can use a project API token instead (Studio → your project → Settings → API tokens), sent as Authorization: Bearer colophon_api_…. A token is limited to the project's content; managing members, roles and tokens needs the sign-in connection.

What it can do, and what stays with you

Everything you can do in the Studio, in the projects you approve, except deleting a project. It acts as you, with your role, so it can never do more than you can. Anything that publishes, removes, revokes, or changes who can do what asks you first: the app shows you exactly what it would do, and only goes ahead after you say yes. See and revoke connected apps any time in the Studio's account menu, under Connected apps; changing your password disconnects them all.
