# Master specification

- `Rust_Svelte_CMS_Master_Specification.docx`: the original *Complete Product + Engineering Specification: Rust + Svelte
  CMS* (Akira Shirase OSS, 22 October 2026). It superseded all earlier CMS blueprints.
- `master-spec.txt`: a plain-text extraction of the same document (macOS `textutil`), kept so it can be searched with
  `grep`. Tables are flattened to one cell per line.

Colophon CMS derives from this specification but deliberately narrows and reframes it. Every deviation is recorded in
[../DECISIONS.md](../DECISIONS.md). Section references in the Colophon docs use the spec's numbering (for example
"spec §14" means *14 / Publishing and release consistency*).

The spec itself states that it is a design, not evidence: no repository, deployment, benchmark or security audit
existed when it was written.
