# Brand

![Colophon mark](colophon-mark.svg)

## Logo

- **Lockup:** the octagonal **C** mark, the word **Colophon** in a heavy geometric sans, and **CMS** in small, widely
  letter-spaced capitals, all in near-black on white. Shared by the maintainer on 2026-10-25.
- **`colophon-mark.svg`** is a vector *recreation* of the mark, traced from a screenshot of the lockup. It uses
  `currentColor`, so it follows the surrounding text colour, which covers light mode, dark mode and favicons.
- **To do:** add the original logo files here (SVG preferred, plus a PNG lockup) and replace the recreation. The
  wordmark's typeface has not been identified, so the wordmark is not recreated.

## Meaning

The mark is a C drawn like a printer's block: hard edges, 45° cuts, no curves. It matches the project's promise of a
precise, permanent record of what was printed.

## Usage rules (initial)

- The mark is monochrome. Use near-black on light backgrounds and near-white on dark ones; never a gradient.
- Keep clear space around the mark of at least the width of one of its arms.
- At favicon sizes, use the mark alone without the wordmark.
- Colour in product UI comes from the Material 3 scheme (see [DECISIONS.md](../DECISIONS.md), D-011), not from the logo.
