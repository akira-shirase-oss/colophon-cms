# Colophon P0 — a pinned, tested foundation and one rich-text format

Released 2026-10-25: the day its last step, 0.7, merged into `main` (`1455073`). Colophon is pre-release, so there is
no download and no version number; here "released" means the milestone's proof gate passed with its evidence stored.
P0 built nothing an editor would use yet. It pinned the tools, made a local stack that proves each service works, set
the rule that every feature ships with tests, a testbed page and a load scenario, and settled the rich-text format
with an editor, a validator and a renderer that agree byte for byte.

## Highlights

**One rich-text format, and three implementations that agree.** `colophon/rich-text` v1 ([D-021](../DECISIONS.md)) is
Tiptap JSON behind an allowlist, with limits, a canonical form and error codes. The editor opens a document only if it
can give it back byte for byte (D-022), the Rust validator stores exactly one form of it and refuses anything else with
a code and a JSON Pointer, and one renderer draws it for both the Studio's preview and the public site (D-023). Shared
fixtures hold all three to the same answers. Stored v1 documents stay valid for good.

**A local stack that proves each service works.** `scripts/stack.sh up` starts PostgreSQL, Valkey, Garage and
Keycloak, pinned by digest and bound to `127.0.0.1`, and runs 28 checks through their published ports, including that
each service refuses what it must (D-015 to D-017).

**The testing rule.** Every feature gets regression tests, a page in `apps/testbed` that drives the real API, and a k6
load scenario whose results are committed with the machine they ran on, failures included (D-018).
`scripts/check.sh` runs exactly what CI runs (D-014).

## Known issues and limits

- **The Studio's look did not last.** Step 0.7's Material 3 tokens and components were replaced in step 3.5 (D-053,
  then D-056), which superseded D-011, D-024 and D-025.
- **No OpenAPI document.** D-027 chose utoipa to generate one from the code, to take effect with the first `/api/v1`
  resource in P1; it was carried forward and still doesn't exist.
- **Rich text v1 has no tables, embeds or footnotes** (D-021). They can come in a v2 with its own fixtures.
- **Garage lacks bucket versioning, object lock and bucket policies** (D-016), so local public and private objects
  need separate buckets; nothing stores media yet (P4).
- **The Studio was an editor spike.** It edited a document in the browser; nothing was saved to a server until P1.
- **Load figures come from one laptop**, an Apple M2 Pro with 12 cores, sharing the machine with k6 and Docker: they
  are evidence about the code, not a capacity claim (D-018).

## Evidence for this milestone

The proof gate ([ROADMAP.md](../ROADMAP.md)): valid fixtures round-trip through editor, JSON, the Rust validator and
the renderer; invalid fixtures are refused with field paths; CI is green from a clean clone.

- **CI** passed on `1455073`, P0's last merge (GitHub Actions run 40237116812), and on every P0 merge before it.
- **Fixtures:** all 12 valid documents round-trip byte for byte through the editor and the validator and render to
  their reviewed HTML (`fixtures/rich-text/v1/rendered/`); all 34 invalid ones are refused with exactly their code
  and JSON Pointer. Tests: 54 Vitest and 50 Playwright tests for the editor (0.4), 62 Vitest and 14 Playwright tests
  for the renderer (0.6), 116 token contrast tests and axe in four theme and contrast combinations (0.7).
- **Fault cases and simulator:** none yet; F01 and the simulator begin in P1.
- **Load**, all on `apple-m2-pro-12c` (Apple M2 Pro, 12 cores, 32 GB), k6 on the same machine:
  - health: [1,000,000 requests at 74,613/s, p99 2.16 ms](../../perf/results/2026-10-25T185409Z-throughput-apple-m2-pro-12c.json),

## Verify the download

There is no download before v0.1: Colophon is built from source. To check that a checkout contains all of P0:

```sh
git merge-base --is-ancestor 1455073 HEAD && echo "P0 is in this checkout"
```

Checksums, signatures and an SBOM come with the first release (module 19, P6).
