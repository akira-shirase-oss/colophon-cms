# Changelog — @colophon-cms/rich-text

This package is versioned with the server and every other Colophon package (one version, D-062),
so its changes are recorded with everything else in the repository's
[CHANGELOG.md](https://github.com/akira-shirase-oss/colophon-cms/blob/main/CHANGELOG.md): look
for the lines that name `@colophon-cms/rich-text` or the renderer. `RENDERER_VERSION` changes
whenever the HTML it writes for the same document changes.
