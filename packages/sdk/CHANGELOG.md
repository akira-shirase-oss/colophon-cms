# Changelog — @colophon-cms/sdk

The SDK is versioned with the server and every other Colophon package (one version, D-062), so
its changes are recorded with everything else in the repository's
[CHANGELOG.md](https://github.com/akira-shirase-oss/colophon-cms/blob/main/CHANGELOG.md): look
for the lines that name the SDK, `@colophon-cms/sdk` or `@colophon-cms/rich-text`. Before 1.0 a
minor release may change `/api/v1` and with it this package's types; `client.compatibility()`
says when this SDK and a server don't fit.
