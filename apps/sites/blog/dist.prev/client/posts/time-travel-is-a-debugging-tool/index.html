Time travel is a debugging tool

"What did the page say last Tuesday?" is a support question with a one-line answer when every release is pinned.

engineeringreleases

Add ?generation= to a delivery read and the answer is the release exactly as it was, including which entries did not exist yet.

The same pin is what makes a cached page safe to serve: the key names the generation, so a stale fill can never poison a newer release. Updated

Every word on this site was published through Colophon as release 5 of the demo-sites project, and this page names the release it was built from.
