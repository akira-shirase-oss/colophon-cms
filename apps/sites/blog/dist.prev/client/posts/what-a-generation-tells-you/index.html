What a generation number tells you

Release 7 always means the same content. That one property, immutability, is what makes rollbacks honest.

releases

Ask a numbered release what it contains and the answer never changes. Generation numbers are identities, not versions.

Rollback, then, is not "go back to 6": it is a new generation whose content happens to match an older one.

Generations only move forward. A stale worker can never promote an older one.

Every word on this site was published through Colophon as release 5 of the demo-sites project, and this page names the release it was built from.
