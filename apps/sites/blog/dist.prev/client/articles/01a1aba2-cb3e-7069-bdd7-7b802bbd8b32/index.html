A second collection, on the same site

The Draft reads two collections now: posts for the running argument, and articles for the pieces that need more room.

Both come through the same delivery API, from the same pinned release. A site is not limited to one collection, and this one is no longer pretending otherwise.

Every word on this site was published through Colophon as release 5 of the demo-sites project, and this page names the release it was built from.
